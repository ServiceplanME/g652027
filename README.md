# The new BMW X5, KSA live presentation

Static site. No build step.

## Structure

- `index.html`: the presentation
- `production-requirements.html`: production requirements, opened from slide 06.4
- `assets/fonts`: BMW Type Next
- `assets/img`: storyboard frames, screensaver keyframes, set mockup, logo
- `assets/video`: reel references
- `assets/js/screen.js`: grille and stripe animations

## Deploy on GitHub Pages

1. Create a repository and upload the contents of this folder to its root.
2. Settings, Pages, Source: deploy from the `main` branch, folder `/ (root)`.
3. The site goes live at `https://<user>.github.io/<repo>/`.

Keep the repository private if the content is confidential. GitHub Pages on a private repository needs a paid plan, and the published site itself is public.

## Controls

Arrow keys or Prev / Next to move, M or Sections for the contents, Home to go back to the first slide.
